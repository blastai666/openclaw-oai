# A股金融日报优化需求

## 核心要求
- **避免大路货**：需要高可行性的分析，不是泛泛而谈
- **精确到板块和个股**：按相对胜率进行排序
- **分类框架重构**：
  - 价值策略
  - 产业策略  
  - 情绪策略
  - 美股映射
  - 事件驱动
- **分析视角**：
  - 聚焦短期相对胜率的边际变化
  - 采用贝叶斯概率视角进行分析

## 当前问题
- 现有分类（技术、资金、基本、情绪）不符合需求
- 缺乏胜率排序和边际变化分析
- 未采用贝叶斯概率框架

## 优化方向
1. **重构选股模型**：从多因子权重调整为基于胜率的贝叶斯框架
2. **重新设计分类体系**：按五大策略维度组织内容
3. **强化边际分析**：重点分析短期胜率变化趋势
4. **提升可行性**：确保推荐具有实际操作价值

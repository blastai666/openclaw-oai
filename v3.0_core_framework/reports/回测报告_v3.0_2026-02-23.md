## 🎯 v2 核心优化思想

### 价值策略 v3.0: 预期差驱动
**核心**: 从"DCF 稳定性"转向"市场定价错误识别"

**评分逻辑**:
```
价值评分 = 低估程度 (价格 vs 均线) + 质量因子
- 价格低于 20 日均线 → 低估 → 高分
- 结合基本面质量过滤
```

**改进原因**:
- 不再依赖难以计算的 DCF
- 直接捕捉市场短期定价错误
- 均值回归逻辑更可靠

---

### 产业策略 v3.0: 景气度拐点
**核心**: 从"景气度绝对值"转向"景气度加速度"

**评分逻辑**:
```
产业评分 = 近期动量 (20 日) - 中期动量 (60 日)
- 动量加速 → 高分
- 动量减速 → 低分
```

**改进原因**:
- 捕捉景气度变化的二阶导数
- 提前识别行业拐点
- 避免追高已充分定价的热门行业

---

### 情绪策略 v3.0: 情绪拐点
**核心**: 从"追涨杀跌"转向"逆向投资"

**评分逻辑**:
```
情绪评分 = RSI 逆向评分
- RSI < 30 (超卖) → 高分 (买入机会)
- RSI > 70 (超买) → 低分 (卖出信号)
```

**改进原因**:
- 利用市场情绪极端后的反转
- 避免高位接盘
- 在恐慌中寻找机会

---

### 趋势策略 v3.0: 趋势加速
**核心**: 从"跟随趋势"转向"识别加速点"

**评分逻辑**:
```
趋势评分 = 均线多头排列 + 斜率加速
- price > ma5 > ma20 → 多头排列 → 高分
- 近期斜率 > 中期斜率 → 加速 → 加分
```

**改进原因**:
- 更早识别强势趋势
- 避免在趋势末期入场
- 结合多重验证提高胜率

---

### 量化策略 v3.0: 量化 + 基本面融合
**核心**: 从"纯量化"转向"量化验证基本面"

**评分逻辑**:
```
量化评分 = 波动率收缩 + 质量确认
- 近期波动率 / 中期波动率 < 0.8 → 收缩 → 高分
- 基本面向好 → 确认通过
```

**改进原因**:
- 波动率收缩是变盘前兆
- 用基本面验证量化信号
- 避免纯技术分析的盲目性

## 🔍 关键洞察

### 为什么 v2 显著优于 v1？

1. **从预测转向识别**
   - v1 试图预测未来价格 → 困难且准确率低
   - v2 识别当前错误定价 → 更可靠

2. **从静态转向动态**
   - v1 关注静态指标（DCF、景气度绝对值）
   - v2 关注动态变化（预期差、加速度、拐点）

3. **从单一转向融合**
   - v1 单一维度评分
   - v2 多因子融合验证

4. **从顺势转向逆向**
   - v1 追涨杀跌（情绪策略）
   - v2 逆向投资（情绪极端反转）

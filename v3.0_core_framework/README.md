## 🧠 核心思想

### 从"预测价格"转向"识别错误定价"

v3.0 的根本性转变：
1. **不再试图预测未来价格** - 市场有效性使得这极其困难
2. **转而识别当前错误定价** - 找到预期差获得超额收益
3. **聚焦边际变化** - 关注变化率而非绝对值
4. **逆向投资** - 利用市场情绪极端后的反转

---

## 📈 五大策略 v3.0

### 1. 价值策略 v3.0: 预期差驱动
**核心**: 市场定价错误 vs 真实价值的差距

**评分权重**:
- 预期差 (40%): 财报后价格反应代理
- 估值修复 (30%): PE 历史分位数
- 质量因子 (20%): ROE>20%、波动率低
- 安全边际 (10%): 负债率<60%、利息覆盖>3 倍

**关键指标**:
```python
价值评分 = 低估程度 (价格 vs 均线) + 质量因子
- 价格低于 20 日均线 → 低估 → 高分
```

---

### 2. 产业策略 v3.0: 景气度拐点
**核心**: 景气度超预期，而非景气度绝对值

**评分权重**:
- 景气加速 (35%): 20 日动量 -60 日动量
- 政策变化 (25%): 近期政策数 vs 历史平均
- 供需矛盾 (25%): 量价关系
- 产业链验证 (15%): 上下游一致性

**关键指标**:
```python
产业评分 = 近期动量 (20 日) - 中期动量 (60 日)
- 动量加速 → 高分
```

---

### 3. 情绪策略 v3.0: 情绪拐点
**核心**: 逆向投资，情绪极端后的反转

**评分权重**:
- 情绪极端 (40%): RSI 超买超卖
- 拐点信号 (30%): 成交量突变 + 价格反转
- 板块梯队 (20%): 龙头 vs 跟风
- 资金分歧 (10%): 机构 vs 散户

**关键指标**:
```python
情绪评分 = RSI 逆向评分
- RSI < 30 (超卖) → 高分 (买入机会)
- RSI > 70 (超买) → 低分 (卖出信号)
```

---

### 4. 趋势策略 v3.0: 趋势加速
**核心**: 识别趋势强化而非趋势本身

**评分权重**:
- 趋势强度 (35%): 均线系统排列
- 趋势加速 (30%): 斜率变化
- 产业链验证 (20%): 上下游一致性
- 技术破位 (15%): 关键支撑/阻力

**关键指标**:
```python
趋势评分 = 均线多头排列 + 斜率加速
- price > ma5 > ma20 → 多头排列 → 高分
```

---

### 5. 量化策略 v3.0: 量化 + 基本面融合
**核心**: 用量化方法验证基本面逻辑

**评分权重**:
- 波动率收缩 (30%): 变盘前兆
- 换手率异常 (25%): 资金异动
- 热门度 (25%): 市场关注度
- 基本面确认 (20%): 量化信号的基本面验证

**关键指标**:
```python
量化评分 = 波动率收缩 + 质量确认
- 近期波动率 / 中期波动率 < 0.8 → 收缩 → 高分
```

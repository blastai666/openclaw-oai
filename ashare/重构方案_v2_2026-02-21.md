# A 股金融日报重构方案 v2.0

## 外部参考总结

### 券商研报框架（中信/中金/华泰 2026 策略）
- **核心线索**：AI 产业趋势、"涨价链"、"出海链"、内需结构性复苏
- **因子投资**：价值 (Value)、规模 (Size)、动量 (Momentum)、质量 (Quality)、低波 (Low Vol)
- **配置逻辑**：从"竞速模式"筛选优胜行业 → 盈利复苏通道的行业

### 贝叶斯概率在交易中的应用
- **核心公式**：P(A|B) = P(B|A) × P(A) / P(B)
- **应用场景**：
  - 基于先验概率更新后验胜率
  - 动态调整策略权重
  - PIN (Probability of Informed Trading) 每日更新

### 主流平台分类体系
- **同花顺**：概念板块（自主编制）、行业板块（申万分类）
- **东方财富**：概念板块、行业板块、地区板块
- **分类维度**：行业 + 概念 + 策略 三维交叉

## 新框架设计

### 一、策略分类（五大维度）

| 策略 | 核心逻辑 | 关键指标 | 适用场景 |
|------|----------|----------|----------|
| **价值策略** | 低估值 + 高股息 + 稳定现金流 | PE<20, PB<3, 股息率>3% | 防御配置 |
| **产业策略** | 产业政策 + 景气度上行 | 板块涨幅>5%, 量能放大 | 趋势跟随 |
| **情绪策略** | 市场情绪 + 资金流向 + 技术形态 | 换手率 5-15%, 涨幅 3-7% | 短线交易 |
| **美股映射** | 美股龙头→A 股相关板块 | 美股对应板块涨幅>2% | 跨市场套利 |
| **事件驱动** | 财报/政策/行业事件催化 | 突发公告、政策发布 | 短期催化 |

### 二、贝叶斯胜率计算模型

```
先验概率 P(A) = 策略历史胜率（过去 20 日）
条件概率 P(B|A) = 当前市场环境下策略有效性
后验概率 P(A|B) = 更新后的策略胜率

个股胜率 = 策略胜率 × 个股因子得分 × 行业/概念调整系数
```

### 三、报告结构（先总后分）

```
1. 市场概况
   - 上证指数/成交量/涨跌家数
   - 市场情绪指标

2. 策略胜率总览（核心）
   - 五大策略当前胜率
   - 边际变化（vs 昨日）
   - 变化理由（三位一体）

3. 各策略详细分析
   3.1 价值策略
       - 策略逻辑与当前适配性
       - 板块/行业分布
       - 个股推荐（按胜率排序）
   3.2 产业策略
       ...
   3.3 情绪策略
       ...
   3.4 美股映射
       - 美股表现
       - A 股映射标的
   3.5 事件驱动
       - 今日重要事件
       - 受益标的

4. 交叉分析
   - 行业×策略矩阵
   - 概念×策略矩阵

5. 操作建议
   - 仓位配置
   - 风险提示
```

### 四、个股细分分类

每个推荐标的包含：
- **代码 + 名称**
- **胜率**（贝叶斯后验概率）
- **策略分类**（主策略 + 次策略）
- **行业分类**（申万一级/二级）
- **概念分类**（同花顺概念 TOP3）
- **选出理由**（3 条以内）
- **关键数据**（价格、涨跌、成交、换手、PE）

### 五、持续优化机制

1. **每日验证**：记录推荐标的次日表现
2. **胜率更新**：根据实际表现更新先验概率
3. **里程碑反思**：重大改进时写入长期记忆
4. **外部对比**：定期对比券商/AI/社交媒体观点

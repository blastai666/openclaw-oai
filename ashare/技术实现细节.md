# A股高可行性日报系统 - 技术实现细节

## 📁 文件结构
```
asharereport/
├── A股高可行性日报系统文档.md      # 系统概述和使用指南
├── 技术实现细节.md                   # 详细技术实现
├── concept_mapping.json              # 概念映射数据库 (5561只股票)
├── price_data/
│   ├── latest_trading_day.csv       # 最近交易日数据 (5810只股票)
│   └── historical/                  # 历史数据 (106只股票)
│       ├── historical_batch_1_200.json
│       └── ...
└── scripts/
    ├── stock_selector_v5.py         # 主要选股脚本
    ├── fetch_concept_mapping.py     # 概念映射获取脚本
    ├── fetch_latest_trading_day.py  # 最近交易日数据获取脚本
    └── fetch_historical_robust.py   # 历史数据获取脚本(稳健版)
```

## 🔧 核心脚本说明

### 1. stock_selector_v5.py
**功能**: 主要选股和日报生成脚本
**输入**: 
- concept_mapping.json (概念映射)
- latest_trading_day.csv (最近交易日数据)
- historical/ (历史数据，按需加载)
**输出**: A股日报 Markdown 文件
**策略分类**:
- 价值策略: 低估值 + 高股息 + 稳定现金流
- 产业策略: 产业政策支持 + 景气度上行  
- 情绪策略: 市场情绪 + 资金流向 + 技术形态
- 美股映射: 跟随美股相关板块表现
- 事件驱动: 财报季、政策发布、行业事件

### 2. fetch_concept_mapping.py
**功能**: 获取全市场股票概念映射
**数据源**: AKShare 东方财富概念板块
**处理逻辑**:
- 获取466个概念板块列表
- 遍历每个概念获取成分股
- 建立股票代码到概念的映射关系
**输出**: concept_mapping.json

### 3. fetch_latest_trading_day.py  
**功能**: 获取最近交易日完整行情数据
**数据源**: AKShare 实时行情接口
**处理逻辑**:
- 获取全市场5810只股票最新数据
- 包含价格、涨跌幅、成交量、换手率等
**输出**: latest_trading_day.csv

### 4. fetch_historical_robust.py
**功能**: 获取历史价格数据(稳健版)
**数据源**: AKShare 日线历史数据
**处理逻辑**:
- 分批处理(每批200只股票)
- 重试机制(3次重试 + 指数退避)
- 增量保存(每成功获取立即保存)
- 错误隔离(单个股票失败不影响整批)
**输出**: historical/ 目录下的批次文件

## 📊 数据获取策略

### 免费API限制应对
1. **频率控制**: 单请求间隔3-5秒
2. **分批处理**: 避免大量连续请求
3. **错误处理**: 自动跳过失败请求
4. **缓存机制**: 已获取数据永久保存

### 按需获取策略
由于完整历史数据获取成本过高，采用按需获取:
1. **核心数据**: 概念映射 + 最近交易日数据 (完整)
2. **历史数据**: 只在需要时获取TOP20股票的历史数据
3. **逐步积累**: 常用股票历史数据逐步缓存到本地

## 🚀 使用指南

### 日常运行
```bash
# 生成日报 (使用现有数据)
python stock_selector_v5.py

# 更新最近交易日数据
python fetch_latest_trading_day.py

# 补充特定股票历史数据
python fetch_historical_robust.py --stocks 000001,600000
```

### 定制化调整
- **策略权重**: 修改 stock_selector_v5.py 中的策略评分逻辑
- **概念关键词**: 扩展 concept_mapping.json 中的概念匹配
- **数据源**: 可替换为其他免费API(如Tushare)

## ⚠️ 注意事项

1. **API限制**: 免费API有频率限制，避免过度请求
2. **数据完整性**: 部分股票可能因停牌等原因数据不完整
3. **周末数据**: 周末A股休市，数据可能不准确
4. **实盘验证**: 建议下周一实盘时验证策略效果

## 📈 优化方向

1. **多数据源融合**: 结合多个免费API提高数据质量
2. **智能缓存**: 根据使用频率自动缓存热门股票数据  
3. **增量更新**: 只获取新增或变化的数据
4. **并行处理**: 在API限制内最大化并行度

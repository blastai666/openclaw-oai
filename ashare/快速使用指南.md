# A股高可行性日报系统 - 快速使用指南

## 📁 文件夹结构
```
asharereport/
├── concept_mapping.json          # 概念映射数据库 (5561只股票)
├── price_data/
│   ├── latest_trading_day.csv    # 最近交易日数据 (5810只股票)
│   └── historical/              # 历史数据 (106只股票)
├── A股高可行性日报系统文档.md   # 系统规则和方法论
├── 技术实现细节.md             # 脚本逻辑和技术细节
├── stock_selector_v5.py         # 主脚本
└── README.md                   # 项目概述
```

## 🚀 快速开始
1. **查看概念数据**: `concept_mapping.json`
2. **获取最新价格**: `price_data/latest_trading_day.csv`
3. **运行日报生成**: `python stock_selector_v5.py`
4. **查看历史数据**: `price_data/historical/` 目录

## 🔧 数据更新策略
- **概念数据**: 已完整获取，无需更新
- **最近交易日**: 每日自动更新
- **历史数据**: 按需获取（TOP20股票）

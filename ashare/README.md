# A 股金融日报任务 - 高可行性版本 v3.0

## 任务概述
每日 08:30 自动生成 A 股金融日报，聚焦短期相对胜率的边际变化，采用贝叶斯概率视角进行分析。

## 核心理念
- **避免大路货**：不做泛泛而谈的技术/资金/基本面分析
- **胜率导向**：所有推荐按相对胜率排序
- **边际变化**：聚焦短期胜率的变化趋势
- **贝叶斯框架**：用概率思维替代简单加权

## 五大策略分类

### 1. 价值策略
- 低估值 + 高股息 + 稳定现金流
- 适合防御性配置
- 关键指标：PE<20, PB<3, 股息率>3%

### 2. 产业策略
- 产业政策支持 + 景气度上行
- 聚焦产业链边际变化
- 关键指标：板块涨幅>5%, 量能放大

### 3. 情绪策略
- 市场情绪 + 资金流向 + 技术形态
- 短期交易机会
- 关键指标：换手率 5-15%, 涨幅 3-7%

### 4. 美股映射
- 美股龙头表现 → A 股相关板块
- 军工、AI 芯片、新能源车、消费电子、生物医药
- 关键指标：美股对应板块涨幅>2%

### 5. 事件驱动
- 财报季、政策发布、行业事件
- 短期催化因素
- 关键指标：突发公告、政策发布

## 输出格式
每日报告包含：
1. 市场概况（上证指数、成交量、涨跌家数）
2. 策略胜率总览（五大策略当前胜率、边际变化、变化理由）
3. 各策略详细分析（策略逻辑、统计、个股推荐）
4. 美股映射分析（美股表现、A 股映射标的）
5. 操作建议（仓位配置、风险控制、关注方向）

## 方法论
- **贝叶斯概率框架**: P(A|B) = P(B|A) × P(A) / P(B)
- **相对胜率排序**: 所有标的按后验胜率排序
- **边际变化分析**: 聚焦短期胜率变化趋势
- **行业/概念交叉**: 三维分类（行业 + 概念 + 策略）

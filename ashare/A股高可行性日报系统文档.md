# A股高可行性日报系统 - 完整技术文档

## 📋 系统概述

本系统旨在生成高可行性的A股金融日报，基于贝叶斯概率视角，聚焦短期相对胜率的边际变化，采用五大策略分类框架。

### 核心理念
- **避免大路货**：不做泛泛而谈的技术/资金/基本面分析
- **胜率导向**：所有推荐按相对胜率排序
- **边际变化**：聚焦短期胜率的变化趋势
- **贝叶斯框架**：用概率思维替代简单加权

### 五大策略分类
1. **价值策略**：低估值 + 高股息 + 稳定现金流
2. **产业策略**：产业政策支持 + 景气度上行
3. **情绪策略**：市场情绪 + 资金流向 + 技术形态
4. **美股映射**：美股龙头表现 → A股相关板块
5. **事件驱动**：财报季、政策发布、行业事件

## 🗃️ 数据源与API

### 主要数据源
- **AKShare**：免费开源财经数据接口库
  - 实时行情数据
  - 概念板块数据（466个概念）
  - 行业分类数据
  - 历史K线数据
- **Yahoo Finance**：美股数据
  - 美股主要标的日线数据
  - 用于美股映射分析

### API使用规则
#### AKShare限制与最佳实践
- **频率限制**：免费API有严格频率限制
- **重试机制**：建议实现3次重试 + 指数退避
- **缓存策略**：已获取数据应本地缓存，避免重复请求
- **错误处理**：单个股票失败应跳过，不影响整体流程

#### 数据获取优先级
1. **概念映射数据**：一次性获取，相对稳定
2. **最近交易日数据**：每日获取，数据量小
3. **历史价格数据**：按需获取，避免批量请求

## 🧠 贝叶斯胜率计算模型

### 模型公式
```
后验胜率 = 先验概率 × 条件概率 × 市场调整因子
```

### 先验概率设置
- **价值策略**：0.50（基准）
- **产业策略**：0.45（依赖政策催化）
- **情绪策略**：0.40（高波动性）
- **美股映射**：0.55（跨市场套利）
- **事件驱动**：0.60（短期爆发力）

### 条件概率计算
基于个股因子：
- **动量因子**：涨跌幅在市场中的相对排名
- **价值因子**：PE倒数，低估值优先
- **流动性因子**：成交额对数归一化
- **换手率因子**：适度换手（3-15%最佳）
- **防御因子**：逆势上涨或跌幅有限
- **规模因子**：中等市值（100-2000亿）优先

### 市场调整因子
根据当日市场环境动态调整：
- **市场下跌**：防御型因子权重提升
- **市场上涨**：动量型因子权重提升
- **震荡市**：价值型因子权重提升

## 📊 报告生成逻辑

### 报告结构（先总后分）
1. **市场概况**
   - 上证指数、成交金额、筛选股票数
2. **策略胜率总览**
   - 五大策略的当前胜率、相对评分、边际变化、变化理由
3. **各策略详细分析**
   - 策略逻辑说明
   - 统计信息（股票数、平均胜率、平均涨幅）
   - 推荐标的（TOP20，按胜率排序）
4. **美股映射分析**
   - 各概念对应的美股表现
   - A股相关标的推荐
5. **操作建议**
   - 仓位配置建议
   - 风险控制原则

### 个股推荐格式
每个推荐标的包含：
- **股票代码和名称**
- **所属行业和概念标签**
- **价格、涨跌幅、成交额、换手率**
- **主要选出理由和策略分类**

### 概念匹配逻辑
1. **概念数据源**：东方财富概念板块（466个概念）
2. **匹配方式**：建立股票代码到概念的映射表
3. **交叉分析**：行业 + 概念 + 策略三维度分析
4. **动态更新**：概念数据定期更新（月度）

## ⚙️ 脚本架构说明

### 核心脚本文件
- `stock_selector_v5.py`：主脚本，集成所有功能
- `fetch_historical_robust.py`：历史数据获取脚本
- `concept_mapping_builder.py`：概念映射构建脚本

### 主要函数说明
- `fetch_us_stock_data()`：获取美股数据
- `fetch_data()`：获取A股市场数据
- `preprocess()`：数据预处理和筛选
- `classify_strategy()`：策略分类和概念匹配
- `calculate_factors()`：多因子得分计算
- `analyze_strategies()`：策略胜率分析
- `generate_report()`：报告生成

### 错误处理机制
- **网络错误**：自动重试3次
- **数据缺失**：使用默认值或跳过
- **API限制**：降低请求频率，分批处理
- **内存溢出**：分批处理，及时释放内存
